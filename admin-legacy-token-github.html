Conectare GitHub

Panoul citește și scrie fișierul cms/content.json din repository.

Cum creezi tokenul: GitHub → Settings → Developer settings → Fine-grained tokens. Repository: doar valmex-site. Permisiune: Contents – Read and write. Setează expirare (30–90 zile). Tokenul rămâne doar în memoria acestei pagini și dispare la reîncărcare. Nu este afișat după conectare. Acest panou nu este o autentificare reală: protecția stă în token.

VALMEX SMART CONVERSION

Popup-uri inteligente

Apar doar când comportamentul vizitatorului arată interes real. Fără popup-uri pe timer, fără insistență după un NU.

Sistemul estimează interesul din interacțiuni și vizibilitate reale (secțiuni văzute, timp activ, calculator, prețuri, revenire). Nu detectează privirea. Urmărirea se activează doar după consimțământul vizitatorului. Popup-urile apar pe site după ce activezi „Sistem activ” și salvezi, iar modificările ajung pe site după îmbinarea ramurii cms-staging în main. Aici nu se verifică încă afișarea reală.
